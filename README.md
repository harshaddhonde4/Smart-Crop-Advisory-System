# 🌱 Smart Crop Advisory System

An intelligent, user-friendly Spring Boot + Thymeleaf application that provides personalized crop recommendations, irrigation guidance, fertilizer schedules, and pest/disease insights based on farmer input.

This system is designed for farmers, students, researchers, and developers exploring modern digital agriculture solutions.

---

## 📌 Key Features

### 🌾 **AI-Ready Crop Advisory**
- Takes user inputs: soil type, season, location, farm size, previous/current crop.
- Generates structured recommendations including:
  - Primary & alternative crops  
  - Sowing period & sunlight needs  
  - Water requirements  
  - Market demand insights  

### 🧪 **Fertilizer & Irrigation Guidance**
- Auto-generated fertilizer mixes (NPK, FYM, micronutrients)  
- Irrigation timing, frequency, and soil moisture suggestions  
- Disease/pest prevention tips  

### 📷 **Pest Detection (UI Ready)**
- Upload system ready for future AI pest/disease image analysis  
- Preview + scan button integrated in UI  

### 🌦 **Weather Alerts Module (UI Ready)**
- Placeholder modal for integrating real-time weather APIs  
- Displays alerts like rainfall, heatwave, humidity spikes  

### 📊 **Interactive Dashboard**
- Farm health score  
- Water usage  
- Pest alerts  
- Cost savings  

### 🌐 **Multi-language Support**
- English / Hindi / Marathi form switching  
- User-friendly for Indian farmers
